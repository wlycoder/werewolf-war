词条介绍

⚡ 迅捷
被召唤的回合即可立即行动。
👣 疾行 X
每回合可额外行动 X 次（基础 1 次 + X）。
🛡 守护
同行友方单位或总部受到伤害时，伤害转移给本守卫（触发时显示 ⚔️ 特效）。
💀 亡语
离场时触发效果。
🚫 禁言
被禁言的单位无法行动，回合结束时会自动解除。
🔙 撤退
使一个单位向自己总部方向后退一行；无处可退则回到手牌。
🩸 血祭X
狼单位被召唤时必须选中 X 个友方民/神单位作为祭品（红色高亮），被选中的单位被献祭。
⚔ 反伤规则（完整）
· 神 → 神：受目标攻击力反伤
· 神 → 民：固定受 1 点反伤
· 神 → 无：无反伤
· 民 → 神：受神攻击力反伤
· 无 → 神：受神攻击力反伤
· 神 → 狼：受狼攻击力反伤
· 无 → 狼：受狼攻击力反伤
· 狼 → 神：受神攻击力反伤
· 狼 → 狼：互受对方攻击力反伤
· 狼 → 民：无反伤
· 狼 → 无：无反伤
· 民 → 狼：无法造成伤害，但受狼攻击力反伤
🃏 卡牌类型
· 单位：召唤到场上作战
· 计：一次性策略，直接打出产生效果
· 策：点击激活（蓝色高亮 ❔），敌方回合达成条件时触发（后从手牌移除）；未触发则下回合开始解除（❓，不返法力）
🎯 射程
默认射程 1 格；带「射程+X」的卡牌可攻击更远的敌人（显示在手牌/卡牌池中）。
🏳 阵营
神 · 民 · 狼 · 无 —— 影响反伤规则。
🟣 行动花费
单位左下角的紫色圆圈显示该单位每次行动消耗的法力。
📦 牌库耗尽
牌库抽完后不再重新补牌，保持 0 张且额外抽牌时对总部造成2点伤害。
🔢 卡牌编号
每张卡牌拥有唯一的 16 进制编号，用于卡组字符串的导入/导出。
📤 导出格式
图标|名称|编号编号编号...，例如 🐺|狼群突袭|10010102...
